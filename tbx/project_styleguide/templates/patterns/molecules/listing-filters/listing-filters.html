{% comment %} Shared multi-select filter component for Work, News, Events listing pages. Native
/ gives collapsible panels with no JavaScript. The whole thing is one GET form. Without JavaScript, "Apply filters" submits it and the page reloads. With JavaScript, HTMX requests the full page whenever a checkbox changes and swaps in #listing-results, #listing-pagination, #listing-active-filters and the text of #listing-status. The dropdowns are never swapped, so their options must not depend on the current selection. The listing-filters JS component hides the Apply button, handles pill removal and "Clear all" without a page reload, and adds outside-click/Escape closing for the dropdowns. The listing filter Jest test will need updating if the dropdown HTML changes, see tbx/static_src/javascript/components/listing-filters.test.js {% endcomment %}
